# Internal Clause and Surface Ledger

This sidecar is an internal traceability artifact and is not part of the public specification.

## Q1/Q2/Q3 surface decisions

| Public surface item | Source evidence | Q1 public contract | Q2 non-derivable | Q3 contract family | Decision |
|---|---|---|---|---|---|
| `Kryo` construction and core graph operations | README Quickstart, Reading and writing objects; public Javadocs | Yes | Yes: null, type, and serializer dispatch paths are library-specific | Yes: supports typed, nullable, and polymorphic operation families | Include |
| `Registration` and `Kryo.register/getRegistration/getSerializer` | README Registration and Default serializers; public Javadocs | Yes | Yes: ID allocation, replacement, and implicit registration rules are library-specific | Yes: supports all registration and lookup cases | Include |
