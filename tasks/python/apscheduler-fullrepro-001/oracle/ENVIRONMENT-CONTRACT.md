# Environment contract

- Python 3.11 or newer on Windows.
- No network access, external services, wall-clock reads, background processes, or installed databases are required.
- The submitted working directory begins empty; no APScheduler implementation
  source or installed APScheduler distribution is supplied to candidates.
- The submitted directory must contain the complete importable `apscheduler`
  package and may use the Python standard library only.
- Only files inside the submitted directory may be changed.
