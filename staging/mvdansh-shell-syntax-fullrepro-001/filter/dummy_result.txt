Passers and why they are kept:

- atomic::TestZeroLinePosInvalid (both modes) — asserts that the zero
  Pos value reports invalid with zero accessors; a stub whose Pos
  methods all return zero values necessarily satisfies it. Inherent to
  the assertion kind (zero-value contract). Its companion
  TestNewPosAccessors fails against the stub in both modes.
- atomic::TestBashRejectsResumeKorn, atomic::TestBashRejectsAtTest
  (reject mode only) — failure_path tests asserting that Bash rejects
  the mksh `;|` case operator and the Bats `@test` declaration. The

  `` `}` can only be used to close a block ``) are not declared in the
  spec, so per the no-spec-widening rule the tests assert only that an
  error occurs, which a reject-all stub necessarily satisfies. Reported
  here; kept.
