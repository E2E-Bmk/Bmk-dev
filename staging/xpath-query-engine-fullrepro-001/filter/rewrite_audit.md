## Shared-helper contract audit

The oracle uses one in-oracle support file per suite
(`oracle/atomic/support_test.go`, `oracle/integration/support_test.go`)
providing only: an in-memory tree builder (`Node` with `Elem`, `Text`,
`Comment`, `Attr`, `NS` constructors), two `NodeNavigator`
implementations over it — one with the optional `NamespaceURL() string`
method, one without — a document constructor per suite, and
compile/select/evaluate wrappers plus equality helpers built on
`t.Fatalf`. Every convention they rely on is stated in the spec: the
navigator method set and semantics (section The Navigator Contract),
the optional namespace extension (sections The Navigator Contract and
Namespace-Aware Matching), and the compile/select/evaluate entry points
(sections Expression Compilation and Reuse; Selection, Evaluation, and
Result Iteration). No environment variables, no file layout
conventions, no CLI flags, no fixture files.
