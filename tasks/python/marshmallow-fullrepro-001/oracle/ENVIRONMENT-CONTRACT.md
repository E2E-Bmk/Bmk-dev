# Environment contract

- Python 3.12 on Windows.
- Runtime code may use only the Python standard library.
- The submitted directory contains `marshmallow/__init__.py` and all supporting modules it imports.
- No Marshmallow source or evolution implementation is present in the starting directory.
- Paths passed to durable APIs are writable local directories.
- UTF-8 text, immutable public snapshots, and exact record ordering are required.
