## Shared-helper contract audit

The oracle uses two small in-oracle support files
(`oracle/atomic/support_test.go`, `oracle/integration/support_test.go`)
providing only: a `parse(t, src, opts...)` wrapper over
`syntax.NewParser(...).Parse(strings.NewReader(src), name)`, a
`printDefault(t, node, opts...)` wrapper over
`syntax.NewPrinter(...).Print`, and equality/contains helpers built on
`t.Fatalf`. Every flag or convention they use (`Parse` name argument,
option values, printer options) is stated in the spec's Parsing Shell
Programs / Canonical Printing sections. No environment variables, no file
layout conventions, no CLI flags.
