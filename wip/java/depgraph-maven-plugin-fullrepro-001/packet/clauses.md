# Clause Traceability — Dependency Graph Maven Plugin

This internal sidecar maps stable clause IDs to verbatim candidate-visible specification sentences. Workflow examples are orientation only and do not establish assessment clauses.

## Execution and Output Lifecycle

- **DGM-EXEC-001** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “The plugin must expose the goal prefix `depgraph` for Maven invocation.”
- **DGM-EXEC-002** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “When `depgraph.skip` is `true`, the selected goal must complete without resolving a graph or writing an output document.”
- **DGM-EXEC-003** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “When `depgraph.skip` is `false`, the selected goal must resolve its public graph view, serialize it in the selected format, and write the resulting UTF-8 document.”
- **DGM-EXEC-004** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “When `outputDirectory` is absent for a project-based goal, the goal must write into the current project's build directory.”
- **DGM-EXEC-005** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “When `outputDirectory` is absent for `for-artifact` outside a Maven project, the goal must write into the current working directory.”
- **DGM-EXEC-006** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “The `outputFileName` parameter must default to `dependency-graph`.”
- **DGM-EXEC-007** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “When `useArtifactIdInFileName` is `true`, the goal must use the current project's artifact ID instead of `outputFileName`.”
- **DGM-EXEC-008** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “When the selected file name does not end with the selected format's extension, the goal must append `.dot`, `.gml`, `.puml`, `.json`, or `.txt` as appropriate.”
- **DGM-EXEC-009** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “If an output directory does not exist, then the goal must create it before writing the graph document.”
- **DGM-EXEC-010** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “If the graph document cannot be written, then the goal must fail the Maven execution.”
- **DGM-EXEC-011** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “Where `graphFormat` is `dot` and `createImage` is `true`, the goal must retain the DOT source and invoke Graphviz `dot` to create an image whose format is selected by `imageFormat` and defaults to `png`.”
- **DGM-EXEC-012** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “Where `dotExecutable` is present, the goal must invoke that executable instead of resolving `dot` from `PATH`.”
- **DGM-EXEC-013** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “Where `dotArguments` is present, the goal must pass its space-separated arguments to Graphviz in addition to the output format, output path, and DOT source path arguments.”
- **DGM-EXEC-014** — [Execution and Output Lifecycle](../../wip/depgraph-maven-plugin/spec_v1.md#execution-and-output-lifecycle) — “If the configured Graphviz executable is missing, is a directory, is not executable, or returns a nonzero status, then the goal must fail the Maven execution.”
## Goal Views

- **DGM-GOAL-001** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:graph` runs in a multimodule build, the goal must write a dependency graph for every Maven project on which Maven executes the goal.”
- **DGM-GOAL-002** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:by-groupid` runs, the goal must collapse artifacts to group-ID nodes, omit self-references created by that collapse, and retain dependency scope as part of node identity.”
- **DGM-GOAL-003** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:example` runs, the goal must create a deterministic built-in example dependency graph while honoring the same format, filtering, display, merge, output, and style parameters as `depgraph:graph`.”
- **DGM-GOAL-004** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:aggregate` runs at a multimodule root, the goal must write one graph containing the union of accepted dependencies from projects in reactor build order.”
- **DGM-GOAL-005** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `includeParentProjects` is `true` for `aggregate`, the graph must include parent POM projects and parent-to-child module edges.”
- **DGM-GOAL-006** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `includeParentProjects` is `false` for `aggregate`, the graph must omit parent-project nodes that exist only to express module containment.”
- **DGM-GOAL-007** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:aggregate-by-groupid` runs, the goal must aggregate the reactor-wide dependency union into group-ID nodes and omit self-references created by that collapse.”
- **DGM-GOAL-008** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “The group-ID aggregate must include reactor parent relationships as group-level edges.”
- **DGM-GOAL-009** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “The `reduceEdges` parameter must default to `true` for aggregated goals.”
- **DGM-GOAL-010** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `reduceEdges` is `true`, an aggregated goal must omit a non-parent edge whose target remains reachable through another dependency path, preferring paths associated with projects earlier in reactor build order.”
- **DGM-GOAL-011** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `reduceEdges` is `false`, an aggregated goal must retain those redundant dependency edges.”
- **DGM-GOAL-012** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:reactor` runs, the goal must write one graph of Maven reactor project relationships rather than external dependency relationships.”
- **DGM-GOAL-013** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `showGroupIds` or `showVersions` is `true` for `reactor`, the reactor nodes must include the corresponding coordinates.”
- **DGM-GOAL-014** — [Goal Views](../../wip/depgraph-maven-plugin/spec_v1.md#goal-views) — “When `depgraph:for-artifact` runs, the goal must build a dependency graph rooted at the configured external artifact and must not require a Maven project.”
## Artifact Selection and Filtering

- **DGM-FILT-001** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “The `scopes` parameter must accept a list drawn from `compile`, `provided`, `runtime`, `system`, and `test`; when the list is empty, all scopes must be eligible.”
- **DGM-FILT-002** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When `scopes` contains known entries, the graph must include dependencies whose effective Maven scope matches any selected entry.”
- **DGM-FILT-003** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When `scopes` contains an unknown entry, the goal must ignore that entry and continue with the known entries.”
- **DGM-FILT-004** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “The `classpathScope` parameter must apply Maven classpath semantics: `compile` selects compile, provided, and system; `provided` selects provided; `runtime` selects compile and runtime; `system` selects system; and `test` selects all dependency scopes.”
- **DGM-FILT-005** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When both `scopes` and `classpathScope` are configured, the goal must use `scopes` and ignore `classpathScope`.”
- **DGM-FILT-006** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “Where deprecated `scope` is present and `classpathScope` is absent, the goal must treat `scope` as `classpathScope`.”
- **DGM-FILT-007** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “The `includes`, `excludes`, `transitiveIncludes`, `transitiveExcludes`, and `targetIncludes` parameters must accept comma-separated Maven artifact patterns in `groupId:artifactId:type:classifier` order with omitted parts and wildcard matching.”
- **DGM-FILT-008** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When `includes` is nonempty, an artifact must enter the graph only when it matches at least one include pattern.”
- **DGM-FILT-009** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When an artifact matches `excludes`, the graph must omit it even when it matches `includes`.”
- **DGM-FILT-010** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When a transitive artifact does not match `transitiveIncludes` or matches `transitiveExcludes`, the graph must omit that transitive artifact while retaining separately accepted direct dependencies.”
- **DGM-FILT-011** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “Where `targetIncludes` is present, the graph must retain dependency paths leading to matching target artifacts and omit branches that do not lead to a target.”
- **DGM-FILT-012** — [Artifact Selection and Filtering](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-selection-and-filtering) — “When `excludeOptionalDependencies` is `true`, dependency goals must omit optional artifacts.”
## Artifact Identity and Display

- **DGM-ATTR-001** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `showGroupIds`, `showVersions`, `showTypes`, or `showClassifiers` is `true`, artifact nodes must expose the selected coordinate component.”
- **DGM-ATTR-002** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `showOptional` is `true`, optional artifacts must carry an optional marker; when it is `false`, the marker must be absent without removing the artifact.”
- **DGM-ATTR-003** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “Dependency graphs must expose effective Maven scope information for accepted artifacts.”
- **DGM-ATTR-004** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `showDuplicates` is `true` for `graph` or `example`, the graph must include dependencies omitted by Maven as duplicates and distinguish those edges from included edges.”
- **DGM-ATTR-005** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `showConflicts` is `true` for `graph` or `example`, the graph must include dependencies omitted by Maven for version conflicts and distinguish those edges from included edges.”
- **DGM-ATTR-006** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `showVersions` is combined with duplicate or conflict display, the graph must expose the selected and omitted version information needed to compare resolution outcomes.”
- **DGM-ATTR-007** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “Aggregated goals must represent included dependencies only and must not synthesize duplicate or conflict resolution across module perspectives.”
- **DGM-ATTR-008** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `mergeTypes` is `true`, nodes that differ only by Maven artifact type must merge and expose the combined type set where the selected format carries type detail.”
- **DGM-ATTR-009** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `mergeClassifiers` is `true`, nodes that differ only by classifier must merge and expose the combined classifier set where the selected format carries classifier detail.”
- **DGM-ATTR-010** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When `mergeScopes` is `true` for an aggregated goal, nodes that differ only by scope must merge and expose the combined scope set where the selected format carries scope detail.”
- **DGM-ATTR-011** — [Artifact Identity and Display](../../wip/depgraph-maven-plugin/spec_v1.md#artifact-identity-and-display) — “When a merge parameter is `false`, the corresponding coordinate component must remain part of node identity.”
## Format Projections

- **DGM-FMT-001** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “The `graphFormat` parameter must accept `dot`, `gml`, `puml`, `json`, and `text` without case sensitivity and must default to `dot`.”
- **DGM-FMT-002** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “If `graphFormat` has any other value, then the goal must fail the Maven execution.”
- **DGM-FMT-003** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “The DOT projection must return a directed Graphviz source document containing one graph node per selected node and one directed edge per selected dependency relationship.”
- **DGM-FMT-004** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “The GML projection must return a GML document with numeric node references and directed edges that preserve the selected graph relationships.”
- **DGM-FMT-005** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “The PlantUML projection must return a PlantUML component diagram source whose component aliases and arrows preserve the selected graph relationships.”
- **DGM-FMT-006** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v2.md#format-projections) — “The text projection must return a tree-like dependency listing rooted at the selected project or artifact and must mark optional dependencies when optional display is enabled.”
- **DGM-FMT-016** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v2.md#format-projections) — “Each text node label must join its enabled coordinate components with colons in this order: group ID, artifact ID, version, slash-joined types, slash-joined classifiers, and effective scope.”
- **DGM-FMT-017** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v2.md#format-projections) — “When scope display is enabled and a project root or dependency node has no explicit scope, its text label must use `compile` as the effective scope.”
- **DGM-FMT-007** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “When `graphFormat` is `text`, the goal must write the `.txt` document and report the same dependency graph through Maven logging.”
- **DGM-FMT-008** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “The JSON projection must return an object with `graphName`, `artifacts`, and `dependencies` properties.”
- **DGM-FMT-009** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “Each JSON `artifacts` entry must contain stable string `id` and numeric `numericId` references plus the enabled coordinate fields among `groupId`, `artifactId`, `version`, `optional`, `classifiers`, `scopes`, and `types`.”
- **DGM-FMT-010** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “Each JSON `dependencies` entry must contain `from`, `to`, `numericFrom`, `numericTo`, and `resolution`, and must contain an omitted version when conflict-version display requires it.”
- **DGM-FMT-011** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “When `showAllAttributesForJson` is `true`, JSON dependency goals must enable group ID, version, type, and classifier fields regardless of the corresponding display flags.”
- **DGM-FMT-012** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “The `showAllAttributesForJson` parameter must not enable `showDuplicates` or `showConflicts`.”
- **DGM-FMT-013** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “When `showAllAttributesForJson` is `false`, the JSON projection must honor the ordinary display flags.”
- **DGM-FMT-014** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “When `repeatTransitiveDependenciesInTextGraph` is `false`, an aggregated text graph must expand a repeated transitive subtree only on its first occurrence.”
- **DGM-FMT-015** — [Format Projections](../../wip/depgraph-maven-plugin/spec_v1.md#format-projections) — “When `repeatTransitiveDependenciesInTextGraph` is `true`, an aggregated text graph must expand that subtree at every occurrence.”
## DOT Styling

- **DGM-STYLE-001** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “The DOT projection must begin with a built-in default style that distinguishes included, duplicate, conflict, and parent relationships.”
- **DGM-STYLE-002** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “The group-ID goals must apply the built-in group-ID style after the default style.”
- **DGM-STYLE-003** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “The reactor goal must apply the built-in reactor style after the default style.”
- **DGM-STYLE-004** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “Where `customStyleConfiguration` names a filesystem path, the DOT projection must load that JSON document after the built-in styles and use it as an override.”
- **DGM-STYLE-005** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “Where `customStyleConfiguration` begins with `classpath:`, the DOT projection must load the remaining resource name from the plugin classpath and use it as an override.”
- **DGM-STYLE-006** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v2.md#dot-styling) — “The documented style JSON must recognize the top-level object keys `graph`, `default-node`, `default-edge`, `edge-scope-styles`, `edge-resolution-styles`, and `node-styles`.”
- **DGM-STYLE-011** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v2.md#dot-styling) — “The `graph`, `default-node`, and `default-edge` values must be JSON objects containing their respective DOT graph, node, and edge attributes, with node and edge font attributes nested inside font objects.”
- **DGM-STYLE-012** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v2.md#dot-styling) — “The `edge-scope-styles` and `edge-resolution-styles` values must map scope or resolution names to nested edge-style objects.”
- **DGM-STYLE-013** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v2.md#dot-styling) — “The `node-styles` value must map coordinate patterns to nested node-style objects.”
- **DGM-STYLE-007** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “Where multiple style sources define the same effective attribute, the later source must override the earlier value while unrelated defaults remain effective.”
- **DGM-STYLE-008** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “If `customStyleConfiguration` does not exist or cannot be parsed as a supported style document, then the goal must fail the Maven execution.”
- **DGM-STYLE-009** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “When `printStyleConfiguration` is `true` for a DOT graph, the goal must report the effective merged style configuration through Maven logging.”
- **DGM-STYLE-010** — [DOT Styling](../../wip/depgraph-maven-plugin/spec_v1.md#dot-styling) — “When `graphFormat` is not `dot`, DOT-specific custom style, style printing, and image-rendering parameters must not alter the serialized graph state.”

- **DGM-ART-002** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “Where `artifact` is absent, `groupId`, `artifactId`, and `version` must all be present.”

- **DGM-ART-004** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “Where the long coordinate form omits `classifier`, the `classifier` parameter must default to the empty classifier.”
- **DGM-ART-005** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “Where `profiles` is present, the goal must activate those profile IDs while building the artifact's Maven project model.”
- **DGM-ART-006** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “If `artifact` and any of `groupId`, `artifactId`, or `version` are both configured, then the goal must fail the Maven execution.”
- **DGM-ART-007** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “If `artifact` contains fewer than three coordinate parts, then the goal must fail the Maven execution.”
- **DGM-ART-008** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “If `artifact` is absent and any of `groupId`, `artifactId`, or `version` is missing, then the goal must fail the Maven execution.”
- **DGM-ART-009** — [Arbitrary Artifact Resolution](../../wip/depgraph-maven-plugin/spec_v1.md#arbitrary-artifact-resolution) — “If Maven cannot resolve or build the configured artifact, then the goal must fail the Maven execution.”

## Cross-View Invariants

- **DGM-INV-001** — [Cross-View Invariants](../../wip/depgraph-maven-plugin/spec_v1.md#crossview-invariants) — “The per-project `graph`, `by-groupid`, and example views must apply the same common output, format, filtering, and DOT-style parameters to their respective selected graphs.”
- **DGM-INV-002** — [Cross-View Invariants](../../wip/depgraph-maven-plugin/spec_v1.md#crossview-invariants) — “A dependency accepted by scope and coordinate filters must appear consistently as a node and connected edge in DOT, GML, PlantUML, JSON, and text projections of the same goal state.”
- **DGM-INV-003** — [Cross-View Invariants](../../wip/depgraph-maven-plugin/spec_v1.md#crossview-invariants) — “A dependency removed by `excludes`, transitive filtering, target filtering, or `excludeOptionalDependencies` must be absent from every format projection of the same goal state.”
- **DGM-INV-005** — [Cross-View Invariants](../../wip/depgraph-maven-plugin/spec_v1.md#crossview-invariants) — “Enabling a merge parameter must change node identity consistently across graph membership, displayed coordinate sets, and every selected output format.”
- **DGM-INV-006** — [Cross-View Invariants](../../wip/depgraph-maven-plugin/spec_v1.md#crossview-invariants) — “An aggregated graph with edge reduction enabled must preserve reachability between retained nodes even though redundant edges are absent.”
